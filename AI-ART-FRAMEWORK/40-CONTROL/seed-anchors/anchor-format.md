# SEED ANCHOR FORMAT
[ANCHOR] subject-id :: seed :: ref-image-id :: negative-set-id
- subject-id: stable handle (e.g. "kayra-prime")
- seed: base random for the subject
- ref-image-id: strongest reference for identity
- negative-set-id: which negatives to attach
Use one anchor line per subject per project. Store in 50-META/provenance.
