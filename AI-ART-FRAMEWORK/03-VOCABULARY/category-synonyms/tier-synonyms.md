# CATEGORY SYNONYMS — cross-ontology mapping
When building prompts, terms from one ontology category can substitute for another
category when the exact term doesn't fit. These chains are proven stable:

## Style -> Texture bridge
- "watercolor" -> "paper-grain", "wash-effect", "bleeding-edges"
- "oil-paint" -> "impasto", "canvas-texture", "brush-stroke"

## Camera -> Composition bridge
- "wide-angle" -> "exaggerated-perspective", "environmental-context"
- "macro" -> "intimate-scale", "detail-isolation"

## Light -> Color bridge
- "golden-hour" -> "warm-amber", "long-shadow", "low-contrast-warm"
- "neon" -> "magenta-teal", "high-saturation-local", "color-bleed"

## Motion -> Timing bridge
- "slow-mo" -> "weighted-duration", "frame-stretch", "lingering"
- "timelapse" -> "compressed-temporality", "accelerated-decay"

## Sound -> Mood bridge
- "drone" -> "sustained-tension", "unresolved-harmony", "hum"
- "sharp-impact" -> "staccato", "percussive-instant"
