# PRACTICAL LIGHT RULES
- every visible lamp must light something
- practical color tells time: tungsten warm, LED cold, CRT flicker
- window light = time + weather + mood in one prop
- neon = era + location + moral weather
- monitor/phone screen = isolation, information age
- candle/fire = primal, unsteady, sacred or dangerous
- HMI-moonlight = night without losing detail
